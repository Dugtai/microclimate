# Система мониторинга микроклимата школьного кабинета

Учебно-исследовательский и инженерный проект стенда для мониторинга параметров микроклимата в школьном кабинете с передачей показаний через Telegram-бота и VK-бота.

Проект был представлен на краевой научно-практической конференции учащихся «Будущее Хабаровского края в надежных руках» и занял призовое место по направлению «Физико-математические предметы».

## Кратко о проекте

Цель проекта — исследовать микроклимат школьного кабинета и организовать его постоянный автоматизированный мониторинг.

В рамках работы были объединены исследовательская и инженерная части:

- проведены первичные измерения параметров микроклимата;
- выявлена проблема недостаточной освещённости;
- результаты переданы администрации школы;
- после этого была выполнена модернизация освещения;
- разработан автономный стенд мониторинга;
- реализована передача данных пользователю через Telegram и VK;
- настроен автозапуск программной части на Linux.

## Что измеряет система

- температура воздуха;
- относительная влажность;
- освещённость;
- качество воздуха;
- атмосферное давление;
- уровень шума.

## Используемые компоненты

- микрокомпьютер NanoPi-AR;
- датчик BME280 — температура, влажность и атмосферное давление;
- датчик BH1750 — освещённость;
- датчик MQ-135 — качество воздуха;
- датчик MAX4466 — уровень шума;
- ADS1115 — внешний аналого-цифровой преобразователь;
- LCD-дисплей;
- макетная плата;
- Wi-Fi-подключение.

## Используемые технологии

- Python 3;
- Linux;
- systemd;
- Telegram Bot API;
- VK API и Long Poll API;
- I2C;
- HTTP/JSON;
- GitHub для публикации проекта и портфолио.

## Возможности ботов

Telegram-бот и VK-бот позволяют получать данные удалённо. В проекте предусмотрены команды:

```text
/status       — текущие показатели всех датчиков
/temperature  — температура
/humidity     — влажность
/light        — освещённость
/air          — качество воздуха
/pressure     — давление
/help         — справка
```

Также система может формировать уведомления при отклонении параметров от условных пороговых значений.

## Быстрый запуск

```bash
git clone https://github.com/Dugtai/microclimate.git
cd microclimate
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

После этого необходимо заполнить `.env` реальными токенами Telegram и VK.

Запуск Telegram-бота:

```bash
python src/telegram_bot.py
```

Запуск VK-бота:

```bash
python src/vk_bot.py
```

## Безопасность публикации

В репозиторий не добавляются:

- реальные токены Telegram и VK;
- закрытые ключи;
- MAC-адреса устройств;
- приватные IP-адреса школьной сети;
- персональные данные обучающихся;
- фотографии детей без согласия на публикацию.

Для настройки используется только файл `.env.example`.

## Практический результат

Проект не ограничился демонстрацией стенда. Первичные измерения показали, что освещённость в кабинете находилась на нижней границе рекомендуемых значений. После передачи результатов администрации школы освещение было модернизировано, а повторные измерения показали улучшение условий.
