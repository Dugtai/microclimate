# Система мониторинга микроклимата школьного кабинета

Учебно-исследовательский проект стенда для мониторинга параметров микроклимата в школьном помещении с передачей показаний пользователю через Telegram-бота и VK-бота.

Проект был представлен на краевой научно-практической конференции и занял призовое место.

## Назначение проекта

Цель проекта — создать доступную и наглядную систему, которая позволяет получать данные о состоянии микроклимата в учебном кабинете и демонстрирует практическое применение программирования, датчиков, сетевых технологий и автоматизации на Linux.

Стенд может использоваться:

- в проектной и исследовательской деятельности школьников;
- на занятиях по информатике, технологии и естественно-научным дисциплинам;
- как демонстрационный пример интеграции датчиков, Python и мессенджеров;
- как основа для дальнейшего развития IoT-системы.

## Что умеет система

- считывать параметры микроклимата с подключённых датчиков;
- формировать текстовый отчёт о текущем состоянии среды;
- отправлять данные через Telegram-бота;
- отправлять данные через VK-бота как резервный канал;
- запускаться автоматически через `systemd`;
- восстанавливаться после перезагрузки стенда;
- работать как демонстрационный автономный Linux-стенд.

## Используемые технологии

- Python 3;
- Linux;
- systemd;
- Telegram Bot API;

## Быстрый запуск

1. Склонировать репозиторий:

```bash
git clone https://github.com/Dugtai/microclimate.git
cd microclimate
```

2. Создать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Установить зависимости:

```bash
pip install -r requirements.txt
```

4. Создать файл `.env` на основе примера:

```bash
cp .env.example .env
```

5. Заполнить токены в `.env`:

```env
BOT_TOKEN=telegram_bot_token_here
VK_TOKEN=vk_group_token_here
```

6. Запустить нужный бот:

```bash
python src/telegram_bot.py
```

или:

```bash
python src/vk_bot.py
```

## Безопасность

В репозиторий не добавляются реальные токены, ключи доступа, персональные данные, MAC-адреса устройств, приватные IP-адреса школьной сети и фотографии обучающихся без согласия на публикацию.

Для публикации используется только пример конфигурации `.env.example`.
