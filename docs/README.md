# Каталог `docs`

В этом каталоге находится документация проекта: описание исследования, аппаратной части, программной настройки, системной автоматизации и материалов для НПК.

## Файлы

| Файл | Назначение |
|---|---|
| `project_description.md` | общее описание проекта, цели, актуальность и практическая значимость |
| `hardware.md` | аппаратная часть стенда: NanoPi-AR, датчики, дисплей, подключение |
| `software_setup.md` | настройка Python-окружения, `.env`, запуск Telegram/VK-ботов |
| `system_automation.md` | автозапуск, Wi‑Fi, systemd, watchdog-подход |
| `deployment_on_stand.md` | развёртывание проекта на реальном NanoPi-AR |
| `troubleshooting.md` | устранение типовых неполадок |
| `research_results.md` | исследовательская часть и результаты измерений |
| `bot_commands.md` | команды Telegram/VK-ботов и примеры ответов |
| `scripts_overview.md` | краткая карта всех скриптов проекта |
| `npk_materials.md` | материалы и логика защиты на НПК |
| `conference_result.md` | результат участия в конференции и ценность для портфолио |

## С чего начать

Для быстрого понимания проекта лучше читать документы в таком порядке:

1. `project_description.md`
2. `research_results.md`
3. `hardware.md`
4. `software_setup.md`
5. `scripts_overview.md`
6. `deployment_on_stand.md`
7. `troubleshooting.md`

## Для портфолио

Файлы `conference_result.md`, `npk_materials.md` и главный `README.md` помогают показать проект как законченный инженерный кейс: от исследования до работающего стенда и публичной защиты.
