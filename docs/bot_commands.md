# Команды Telegram/VK-бота

Боты используются для удалённого получения данных со стенда мониторинга микроклимата.

## Основные команды

| Команда | Назначение |
|---|---|
| `/start` | включить авторассылку и уведомления |
| `/stop` | отключить авторассылку и уведомления |
| `/status` | получить все текущие параметры микроклимата |
| `/temperature` | получить температуру |
| `/humidity` | получить влажность |
| `/light` | получить освещённость |
| `/air` | получить качество воздуха |
| `/pressure` | получить атмосферное давление |
| `/id` | показать peer_id / идентификатор получателя |
| `/help` | показать справку |

## Пример ответа на `/status`

```text
📊 Микроклимат кабинета
🕘 30.04.2026 11:58:02

⚠️ Температура: 27.45 °C (ориентир 20.0–24.0 °C)
✅ Влажность: 41.9 % (ориентир 30.0–60.0%)
⚠️ Освещённость: 172 лк (ориентир 200–500 лк)
⚠️ Качество воздуха: 0.89 усл. (ориентир 0.0–0.6)
🌡 Давление: 1006.67 гПа

Учебный проект. Данные в реальном времени.

📌 Рекомендации:
🥵 Температура высокая — рекомендуется проветривание
💡 Недостаточная освещённость — включите освещение
🌫 Плохое качество воздуха — необходимо проветривание
```

## Пример ответа на `/light`

```text
💡 Освещённость: 172 лк
```

## Пример ответа на `/pressure`

```text
📈 Давление: 1006.66 гПа
```

## Автоматические уведомления

При выходе параметров за условные пороговые значения система может автоматически отправлять предупреждение пользователю. Например:

```text
🚨 Обнаружено отклонение микроклимата

⚠️ Температура выше нормы
⚠️ Недостаточная освещённость
⚠️ Плохое качество воздуха

Рекомендации:
- проверить кабинет;
- включить дополнительный свет;
- проветрить помещение.
```
