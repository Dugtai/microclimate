# Аппаратная часть

## Общая схема стенда

Стенд состоит из управляющего устройства под Linux, датчиков микроклимата и сетевого подключения для передачи данных пользователю.

```text
Датчики микроклимата
        │
        ▼
Управляющее устройство / Linux-стенд
        │
        ├── Python-скрипты
        ├── Telegram-бот
        ├── VK-бот
        └── systemd-автозапуск
        │
        ▼
Пользователь получает данные через мессенджер
```

## Основные элементы

- управляющее устройство со средой Linux;
- датчики для измерения параметров микроклимата;
- макетная плата и соединительные провода;
- Wi-Fi-подключение;
- источник питания;
- программные сервисы для обработки и отправки данных.

## Сетевое подключение

Стенд подключается к доступной Wi-Fi-сети. Для устойчивой работы ботов важно, чтобы после перезагрузки устройство автоматически подключалось к известной сети и запускало сервисы.

## Примечание по публикации

В публичный репозиторий не следует добавлять реальные MAC-адреса, внутренние IP-адреса школьной сети, токены и другие чувствительные данные.
