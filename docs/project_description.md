# Описание проекта

## Тема

Система мониторинга микроклимата школьного кабинета.

## Идея проекта

Проект направлен на создание учебно-исследовательского стенда, который позволяет измерять параметры микроклимата в помещении и передавать результаты пользователю через цифровые каналы связи.

Основной акцент сделан не только на измерении температуры и влажности, но и на демонстрации полного инженерного цикла:

- постановка проблемы;
- подбор компонентов;
- сборка стенда;
- написание программного кода;
- настройка Linux-сервиса;
- интеграция с Telegram и VK;
- тестирование;
- представление результата на конференции.

## Актуальность

Качество микроклимата влияет на самочувствие, работоспособность и концентрацию обучающихся. В школьных помещениях важно контролировать температуру, влажность и другие параметры среды.

Проект показывает, как с помощью доступных технических средств можно создать прототип системы мониторинга и использовать его в образовательной деятельности.

## Практическая значимость

Стенд может использоваться:

- для учебных демонстраций;
- для исследовательских проектов школьников;
- для изучения основ IoT;
- для практики программирования на Python;
- для знакомства с Linux и автозапуском сервисов;
- для анализа микроклимата школьного кабинета.

## Основной результат

В результате работы был создан прототип системы, который считывает данные с датчиков и позволяет получать показания через Telegram-бота и VK-бота.
