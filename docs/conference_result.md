# Результат представления проекта

Проект системы мониторинга микроклимата школьного кабинета был представлен на краевой научно-практической конференции и занял призовое место.

## Сильные стороны проекта

- практическая направленность;
- работающий технический стенд;
- интеграция аппаратной и программной частей;
- использование Python и Linux;
- передача данных через Telegram и VK;
- возможность дальнейшего развития;
- понятная образовательная ценность.

## Что было продемонстрировано

- сборка и настройка стенда;
- получение данных от датчиков;
- запуск программных сервисов;
- работа Telegram-бота;
- работа VK-бота как резервного канала;
- практическая применимость решения для школы.

## Значение для портфолио

Репозиторий фиксирует результат работы над проектом и может использоваться как портфолио-кейс, показывающий навыки в следующих областях:

- Python-разработка;
- Linux-администрирование;
- работа с API мессенджеров;
- настройка автозапуска через systemd;
- проектирование учебного инженерного стенда;
- документирование технического проекта.
