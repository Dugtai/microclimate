# Каталог `src`

В этом каталоге находится программная часть проекта: чтение показаний, анализ микроклимата, Telegram/VK-боты, локальный мониторинг, логирование и контроль отклонений.

## Основные файлы

| Файл | Назначение |
|---|---|
| `microclimate_core.py` | центральная логика проекта: получение данных, анализ, рекомендации, форматирование сообщений |
| `thresholds.py` | условные пороговые значения параметров микроклимата |
| `sensors_live.py` | базовая демонстрационная версия чтения датчиков |
| `telegram_bot.py` | простая версия Telegram-бота |
| `telegram_bot_full.py` | расширенная версия Telegram-бота со всеми командами |
| `vk_bot.py` | простая версия VK-бота |
| `vk_bot_full.py` | расширенная версия VK-бота со всеми командами |
| `data_logger.py` | запись истории измерений в CSV-файл |
| `console_monitor.py` | вывод текущих данных в консоль |
| `display_monitor.py` | заготовка вывода данных на LCD/экран |
| `alert_monitor.py` | контроль отклонений с подтверждением нескольких измерений |
| `alert_daemon.py` | фоновая заготовка для уведомлений об отклонениях |

## Что запускать для проверки

Из корня репозитория:

```bash
source .venv/bin/activate
python src/console_monitor.py
python src/data_logger.py
python src/telegram_bot_full.py
python src/vk_bot_full.py
```

## Важное замечание

Публичная версия использует безопасные демонстрационные значения. На реальном стенде функцию чтения данных можно заменить на работу с BME280, BH1750, MQ-135, MAX4466 и ADS1115.
