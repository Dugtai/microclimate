# Каталог `media`

В этом каталоге можно хранить изображения и визуальные материалы проекта: фотографии стенда, схемы, скриншоты ботов и обработанные материалы с конференции.

## Что можно добавить

| Тип материала | Назначение |
|---|---|
| фото стенда | показать внешний вид и сборку устройства |
| схема подключения | быстро объяснить архитектуру аппаратной части |
| скриншоты Telegram-бота | показать удалённое получение показаний |
| скриншоты VK-бота | показать резервный канал через VK API |
| фото дисплея/LCD | показать локальный вывод параметров |
| фото диплома/грамоты | подтвердить результат НПК, если персональные данные можно публиковать |
| изображения с конференции | использовать только при наличии согласия на публикацию |

## Рекомендуемая структура

```text
media/
├── stand/
│   └── stand-photo.jpg
├── screenshots/
│   ├── telegram-status.png
│   └── vk-status.png
├── schemes/
│   └── architecture.png
└── conference/
    └── diploma-public.png
```

## Что нужно скрыть перед публикацией

Перед загрузкой в публичный репозиторий рекомендуется замазать или удалить:

- лица обучающихся без согласия;
- токены и ключи доступа;
- QR-коды, если они ведут к закрытым ботам или сообществам;
- номера телефонов;
- внутренние IP-адреса;
- MAC-адреса;
- peer_id, chat_id и другие идентификаторы;
- персональные данные школы, участников и руководителя, если их нельзя публиковать.

## Практический совет

Для портфолио достаточно 3–5 очищенных изображений:

1. общий вид стенда;
2. схема архитектуры;
3. скриншот команды `/status` в Telegram;
4. скриншот ответа VK-бота;
5. обработанное фото диплома или грамоты.
