# Медиафайлы проекта

В этот каталог можно добавить изображения, которые не содержат персональных данных:

- фотографии стенда;
- схему подключения;
- скриншоты работы Telegram-бота;
- скриншоты работы VK-бота;
- фотографии диплома или грамоты без лишних персональных данных;
- изображения с конференции, если есть согласие на публикацию.

Перед публикацией рекомендуется скрыть:

- лица обучающихся без согласия;
- токены и ключи;
- номера телефонов;
- внутренние IP-адреса;
- MAC-адреса;
- персональные данные школы и участников, если их нельзя публиковать.
