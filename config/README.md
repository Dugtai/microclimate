# Каталог `config`

В этом каталоге находятся примеры конфигурационных файлов для стенда.

## Файлы

| Файл | Назначение |
|---|---|
| `sensors.example.json` | пример описания подключённых датчиков, адресов I2C, каналов АЦП и параметров стенда |

## Как использовать

Пример конфигурации можно скопировать в локальный рабочий файл:

```bash
cp config/sensors.example.json config/sensors.json
```

После этого `config/sensors.json` можно адаптировать под конкретный стенд.

## Что нельзя публиковать

В публичный репозиторий не следует добавлять:

- реальные пароли Wi‑Fi;
- токены Telegram/VK;
- внутренние IP-адреса;
- MAC-адреса;
- уникальные идентификаторы пользователей;
- чувствительные сведения о школьной сети.

## Примечание

Файл `sensors.example.json` является безопасным шаблоном. Он не содержит закрытых данных и нужен для понимания структуры конфигурации проекта.
